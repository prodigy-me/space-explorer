# 🚀 Space Explorer

An interactive website that teaches space science and exploration in a fun, visual way.

**Live site:** [https://neevgohel.github.io/space-explorer](https://neevgohel.github.io/space-explorer)
*(Replace `neevgohel` with your actual GitHub username)*

---

## Features

- 🌌 **Animated starfield** background with nebula glow effects
- ☀️ **Solar System explorer** — click any planet to see facts, stats and moons
- 🔭 **Concept flip cards** — Black Holes, Wormholes, Neutron Stars, Dark Matter, and more
- 🌠 **Space Exploration Timeline** — scrollable history from Sputnik (1957) to James Webb (2022)
- 🧠 **Space IQ Quiz** — 10 questions with instant feedback and scoring
- 📡 **Random Space Facts** generator
- 👤 **About Neev** — creator profile section

## Tech Stack

- Pure HTML, CSS, and JavaScript — no frameworks, no build tools
- Works in any modern browser
- Fully self-contained (profile photo embedded as base64)

## How to Run Locally

Just open `index.html` in any web browser. No server or install needed.
